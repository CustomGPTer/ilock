Release notes

What changed in each version of iLock. The newest is at the top.

Version 1.0.2 16 November 2026Latest

  • Six kinds of code: a 4-digit PIN, a 6-digit PIN, a PIN of any length, a password, a pattern and a knock code.
  • Fingerprint or face unlock, with the option to ask for it as soon as the lock appears.
  • A recovery code shown once at setup, and an optional security question.
  • Locking by accessibility service, with a back-up route through usage access.
  • A cover that hides a locked app while the lock screen opens.
  • A default relock rule (on leaving, after 1, 5 or 15 minutes, or when the screen turns off) and a separate rule for any app.
  • A safe time window with no locks, and a 15-minute pause.
  • The Quick Lock home-screen widget and quick-settings tile.
  • Hand-over mode, which locks everything except the apps you allow.
  • Tamper protection: locking Settings and uninstall prompts, locking the app stores, and asking Android to refuse to uninstall iLock.
  • A notification with a Lock button when a new app is installed.
  • A chosen number of wrong tries, then waits of 30 seconds, 1 minute and 5 minutes.
  • An optional intruder photo, and a log of every unlock and wrong code.
  • Notification privacy for each locked app: mask or hide, with the originals kept in iLock.
  • A fake crash cover for any locked app, and a Calculator disguise for iLock itself.
  • A lock screen that takes on the locked app's colour, a scrambled keypad, hidden key presses and a hidden pattern line.
  • Dark, light and follow-the-phone themes.
  • A Home screen that shows whether protection is working and what needs fixing.

Checking your download

The file for version 1.0.2 is called iLock.apk. It is 3.6 MB (3,621,304 bytes). Its SHA-256 checksum is:

178a59d021852fd770e088a8a83c036323be526feb1a5b68f4f183ec0b13a12b

On Windows, run certutil -hashfile iLock.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
